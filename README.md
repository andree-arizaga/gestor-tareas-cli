# Gestor de Tareas CLI

Aplicación de consola en Python para gestionar una lista de tareas: agregar, listar, completar y eliminar.

## Requisitos previos

- Python 3.8 o superior
- Git (para clonar el repositorio)

## Instrucciones de uso

1. Clonar el repositorio:
   git clone https://github.com/andree-arizaga/gestor-tareas-cli.git
2. Entrar a la carpeta:
   cd gestor-tareas-cli
3. Ejecutar la aplicación:
   python app.py
4. Elegir una opción del menú escribiendo su número y presionando Enter.
